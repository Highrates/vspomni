# Оптовый каталог и менеджерская

`/opt` ведёт в каталог с доступом владельцу. `/opt/admin` ведёт в менеджерскую того же оптового приложения. Приложение проверяет вход и роль перед показом заказов.

По умолчанию оба адреса перенаправляют на существующую закрытую версию. При переносе приложения задайте `OPT_CATALOG_URL`. Менеджерская использует путь `/orders` на том же домене. Для другого адреса панели задайте `OPT_ADMIN_URL`.

После выкладки проверьте заголовок Location у `/opt` и `/opt/admin`, вход владельца и отказ в доступе к заказам без авторизации.
