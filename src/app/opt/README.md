# Оптовый каталог на VPS

На сервере магазина Nginx направляет точный путь `/opt` и пути `/opt/` в самостоятельное приложение на `127.0.0.1:3327`. Готовые правила для TLS-виртуального хоста находятся в `nginx.locations.conf`. Перед подключением проверьте существующую конфигурацию: на рабочем VPS эти правила уже установлены.

Каталог открывается по `https://vspomni.store/opt`, менеджерская — по `https://vspomni.store/opt/admin`. Без сессии оба адреса открывают форму входа на основном домене. Настройка `OPT_OWNER_ONLY=true` ограничивает доступ владельцем.

Рабочая служба — `vspomni-opt.service`, релиз — `/srv/vspomni-opt/current`. База SQLite и закрытые платёжные документы хранятся в `/var/lib/vspomni-opt`. Копии создаёт `vspomni-opt-backup.timer`. Приложение и каталог с закупочными ценами передаются разработчику приватно.
